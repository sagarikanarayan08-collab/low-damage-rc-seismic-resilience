# Inter-Storey Drift Analysis

## Objective

The analysis evaluates the distribution of lateral deformation and inter-storey drift across the height of the representative RC building.

## Parameters

- Number of storeys: 6
- Storey height: 3.2 m
- Structural system: RC moment-resisting frame
- Analysis type: Preliminary numerical study

## Key Response Parameter

The inter-storey drift ratio is calculated as:

IDR = (Δi - Δi-1) / hi

where:

- Δi = lateral displacement at storey i
- Δi-1 = lateral displacement at the storey below
- hi = storey height

## Preliminary Observation

The drift profile is expected to increase with building height, with the maximum deformation generally occurring in the upper storeys.

Further analysis will replace the preliminary displacement values with results obtained from nonlinear seismic analysis.
